### Python Scientific Calculator Version - 1.0 ###

A command-line scientific calculator built entirely using Python. It features 14 individual mathematical functions and an expression evaluator that supports five arithmetic operators with standard operator precedence.

Features

### Individual Mathematical Operations
- Addition
- Subtraction
- Multiplication
- Division
- Square Root
- Power
- Logarithm (Natural Log)
- Sine
- Cosine
- Tangent
- Factorial
- Absolute Value
- Percentage
- Modulo

### Multiple Operations
- Supports `+`, `-`, `*`, `/`, and `%`.
- Handles multiple arithmetic operations in a single expression.
- Follows standard operator precedence.
- Supports negative numbers and decimal values.
- Includes basic expression validation and error handling.

## Requirements

- Python 3.x
- No external libraries required. Uses Python's built-in `math` module.

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/python-calculator.git
```

### 2. Navigate to the Project Directory

```bash
cd python-calculator
```

### 3. Run the Calculator

```bash
python3 main.py
```

## Version 1.0 Limitations

- Expression evaluation currently supports five arithmetic operators.
- Parentheses are not supported.
- Mathematical functions cannot currently be used inside expressions.
- The calculator runs through a command-line interface.
